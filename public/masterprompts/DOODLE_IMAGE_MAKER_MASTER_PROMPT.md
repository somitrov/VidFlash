=====================================================================
THE MARKER RULE — CRITICAL
=====================================================================

The marker is one of the strongest parts of the visual identity.

Use a BROAD, THICK, DARK BLACK MARKER.

The visual stroke should resemble approximately a 5–8 mm broad whiteboard
or felt-tip marker when viewed at normal presentation size.

The exact physical millimeter measurement is less important than the
VISUAL IMPRESSION of a broad marker.

The stroke must be:

- thick
- bold
- clearly visible
- confidently drawn
- slightly organic
- hand-drawn
- consistent
- dark
- substantial enough to remain readable at 16:9 video scale

The marker should feel like a real physical marker touching a whiteboard.

Use:

- broad black outlines
- thick black internal lines
- bold handwritten lettering
- occasional slight natural variation in stroke thickness
- strong confident contours
- natural marker overlap
- slightly imperfect human-drawn edges

The marker must NOT be:

- thin
- pencil-like
- hairline
- technical
- delicate
- overly smooth vector linework
- brush-painting
- watercolor
- airbrush
- calligraphy pen
- comic-book ink
- scratchy pencil


=====================================================================
MARKER HARDNESS
=====================================================================

The marker should have a FIRM, CONTROLLED, MEDIUM-HARD marker character.

It should not look soft or watery.

It should not look like a paintbrush.

It should not look like charcoal.

It should not have fuzzy edges.

It should not have dripping ink.

It should not have watercolor bleeding.

The stroke should feel:

FIRM + THICK + DARK + CONTROLLED + HAND-DRAWN.

The edges can have very slight natural marker irregularity,
but the illustration must remain clean and readable.

HOW MUCH COLOR TO USE
=====================================================================

Color should be used sparingly.

content unless the narration strongly requires it.

Most scenes should remain overwhelmingly black and white.

Color should feel SPECIAL because it is RARE.

- the key danger
- the key emotional signal

- the object being discussed
- a product being promoted
- the specific item the narration wants the viewer to notice
- the strongest visual metaphor

Examples:

business growth → green growth arrow

important product → selective product-specific color

itself is the key focal element and a subtle accent is justified

=====================================================================
RECURRING CHARACTERS — FLOW #NAME → @NAME
=====================================================================

Flow uses:

#Name

to CREATE and NAME a recurring character reference.

Flow uses:

@Name

to REFER BACK to that generated reference in later scene prompts.

Therefore:

NEVER use @Name unless the corresponding #Name reference has already
been generated.

A recurring character reference is NOT a timeline scene.

It must be created FIRST.


=====================================================================
HOW TO IDENTIFY RECURRING CHARACTERS
=====================================================================

Before writing timeline prompts:

SCAN THE ENTIRE SCRIPT.

Identify every SPECIFIC PERSON who appears in TWO OR MORE visual beats.

Only those recurring specific people receive #Name references.

Do NOT create references for:

- generic groups
- generic crowds
- background people
- one-off characters
- unnamed people appearing only once


=====================================================================
STAGE 1 — CHARACTER REFERENCES
=====================================================================

If recurring characters exist:

FIRST:
identify them from the entire script.

SECOND:
create one #Name reference for each recurring specific person.

THIRD:
STOP.

Do NOT generate timeline scenes yet.

Each reference must establish:

- full-body character
- face
- hairstyle
- body proportions
- clothing silhouette
- distinctive visual cue
- useful signature prop
- marker drawing style
- monochrome character foundation
- expressive face
- readable hands and feet

Character reference backgrounds should remain plain white.

Do not add unnecessary environment detail.


=====================================================================
STAGE 1 CHARACTER REFERENCE FORMAT
=====================================================================

Example:

#RichardLee
full-body professional whiteboard doodle character, approachable adult man,
simplified expressive face, readable eyes, simple eyebrows, simplified nose,
clear expressive mouth, short neatly shaped hair, believable simplified
doodle anatomy, collared shirt, simple trousers, small notebook as
identifying prop, clearly readable hands and shoes, broad thick black
marker strokes, firm medium-hard marker texture, organic but controlled
hand-drawn contours, monochrome black-and-white character design,
professional Doodly and VideoScribe-inspired whiteboard explainer style,
bold hand-drawn proportions, plain clean white background, minimal
secondary detail, no photorealism, no 3D rendering, no anime, no chibi,
no painterly rendering, no watercolor, no glossy CGI


=====================================================================
RECURRING CHARACTER CONSISTENCY
=====================================================================

Once a recurring character reference is created:

DO NOT re-describe the person's appearance in later prompts.

Do NOT write:

"the same man"

"the same trainer"

"Richard Lee with the same appearance"

"Richard Lee with short hair..."

Instead write:

@RichardLee

The @Name reference controls the character's visual identity.


=====================================================================
CHARACTER DIFFERENTIATION
=====================================================================

Since the overall image is mostly monochrome,
differentiate characters using SHAPE, not color.

Use:

- hairstyle
- beard
- glasses
- body shape
- clothing silhouette
- hat
- accessory
- signature prop
- age cues

Avoid assigning arbitrary colors just to distinguish characters.


=====================================================================
IF A PERSON APPEARS ONLY ONCE
=====================================================================

Do NOT create a #Name reference.

Describe them directly in the scene.


=====================================================================

=====================================================================
VISUAL BEAT RULE
=====================================================================

Break narration into meaningful visual beats.

Aim for approximately:

ONE IMAGE EVERY 3–6 SECONDS.

Create a new beat when there is a meaningful change in:

- idea
- subject
- action
- location
- process
- comparison
- metaphor
- visual emphasis

Do NOT mechanically create one image per sentence.

Do NOT create a new image just because one small phrase changes.

Combine related narration into one strong visual composition.


=====================================================================
WHEN TO COMBINE MULTIPLE THINGS
=====================================================================

Combine multiple elements when they are:

- part of the same idea
- part of the same action
- examples of the same concept
- components of one system
- steps of one process
- part of one comparison
- naturally visible together

The purpose is:

ONE IMAGE should communicate the COMPLETE VISUAL IDEA.


=====================================================================
WHEN NOT TO COMBINE
=====================================================================

Create a separate visual beat when there is a meaningful change in:

- subject
- location
- action
- concept
- time
- narrative purpose
- comparison state


=====================================================================
PROCESS VISUALIZATION
=====================================================================

When narration describes a process,
show multiple stages within one coherent whiteboard composition whenever
practical.

Example:

registration → payment → attendance → workout tracking

Create a left-to-right visual flow.

Use:

- simple objects
- thick arrows
- clear grouping
- selective color on the most important stage

Do not automatically split each stage into a separate image.


=====================================================================
SEQUENTIAL STORYTELLING
=====================================================================

For multi-step concepts:

prefer:

STEP 1 → STEP 2 → STEP 3 → RESULT

rather than:

one isolated object per image.

The image should visually explain the relationship.


=====================================================================
LEFT-TO-RIGHT STORY FLOW
=====================================================================

When appropriate, organize visual information:

LEFT → CENTER → RIGHT

This is especially useful for:

- processes
- before/after
- problem/solution
- timelines
- transformations
- cause/effect


=====================================================================
SYMBOL LANGUAGE
=====================================================================

Examples:
