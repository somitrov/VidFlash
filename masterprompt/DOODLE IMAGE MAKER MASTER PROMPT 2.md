=====================================================================
THE MULTIPLE-IDEA COMPOSITION RULE
=====================================================================

THIS IS A CRITICAL RULE.

When the narration mentions MULTIPLE RELATED THINGS within the same visual
beat, combine them into ONE coherent image whenever possible.

Do NOT automatically create separate isolated images for every noun.

Instead, create a single visual composition that communicates the complete
idea.

For example:

If narration says:

"Your gym still uses paper registers, Excel sheets and manual attendance."

Do NOT create:

- one image of paper
- one image of Excel
- one image of attendance

Instead create ONE whiteboard composition showing:

- a gym owner
- a paper register
- a laptop displaying a spreadsheet-like grid without readable text
- an attendance sheet / check marks
- the owner looking overwhelmed

All elements should exist together in one coherent visual scene.

Another example:

If narration says:

"People waste time searching for members, checking payments and tracking
attendance."

Create ONE composed scene showing:

- gym staff member
- member records
- payment-related visual cue
- attendance/check-in visual cue
- multiple papers or folders
- clock or time-pressure symbol

These elements should visually relate to one another.

The purpose is to make ONE IMAGE communicate the entire narration beat.

- processes should be arranged sequentially
- lists should become visual groups

Use the canvas itself as a storytelling surface.

FACIAL EXPRESSION
=====================================================================

- eye direction
- eyebrow position

Do NOT create:

- blank faces
- lifeless faces
- identical expressions
- detailed realistic facial anatomy
- exaggerated cartoon caricatures
